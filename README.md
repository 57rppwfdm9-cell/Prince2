# Agile Project Practice

A lightweight, browser-based practice quiz for PRINCE2 Agile Foundation concepts.

## Run locally

Open `index.html` in a modern web browser. The app has no build step or package dependencies.

## Publish on GitHub Pages

The included GitHub Actions workflow deploys the static app when changes are pushed to `main`. In the repository, open **Settings → Pages** and set the build and deployment source to **GitHub Actions**. After the first successful workflow run, GitHub will show the public site URL under **Settings → Pages**.

## What's included

- 109 original multiple-choice questions, including 53 short scenarios
- Focused practice by topic, including 20 Agile mindset and 20 PRINCE2 roles questions
- Immediate explanations, scoring, and a missed-question review
- Responsive orange-and-white layout

## Study note

This is an independent study aid and is not affiliated with or endorsed by PeopleCert or AXELOS. Questions are original practice questions, not official, recalled, or sponsor-provided exam questions. Check the current official syllabus and exam guidance when preparing for certification.
